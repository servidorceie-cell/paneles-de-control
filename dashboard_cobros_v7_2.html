Conexión a Google Sheets

Lee las hojas CLIENTES, PAGOS y TARIFAS del Sheet de cobros v2. El estado de cada cliente lo calcula n8n y se guarda en CLIENTES; este tablero no lo recalcula, solo lo muestra y lo verifica. La key no está escrita en este archivo: se guarda solo en este navegador (si el navegador lo permite) y se pega una vez. Los datos de ejemplo son ficticios y no tocan tu Sheet. El Sheet debe estar compartido con "cualquier persona con el enlace: lector" para que la key funcione. Restringe la key a Google Sheets API en tu proyecto de Google Cloud.
